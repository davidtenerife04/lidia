# Lidia

Reproductor de música local.

    pip install -r requirements.txt     # y libmpv instalado en el sistema
    python main.py

Estructura: `main.py` (backend), `core/` (BD, escáner, modelos, mpv, portadas), `ui/` (QML).
Atajos: Espacio play/pausa · Ctrl+←/→ anterior/siguiente · Ctrl+F buscar · Esc limpia la búsqueda.
